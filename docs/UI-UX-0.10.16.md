# Catatan UI/UX KonsepSTIFIn 0.10.16

## Arah desain

Identitas visual diarahkan ke gaya edukasi premium yang tenang, jelas, dan mudah dipindai. Warna utama memakai hijau hutan dan hijau mint, dengan latar lembut, kontras teks yang konsisten, radius komponen yang seragam, serta bayangan tipis.

## Cakupan

- Website publik: header, hero, CTA, kartu jalur, katalog, promo, FAQ, modal/form, dan footer.
- Portal anggota: navigasi, kartu dashboard, formulir, tombol, notifikasi, dan tabel.
- Admin dan dashboard: navigasi, kartu statistik, panel, tabel, form, tombol, dan responsivitas layar kecil.

## Prinsip UX

- CTA utama tampak jelas dan konsisten.
- Status aktif dan fokus keyboard terlihat.
- Input dan tombol mempunyai state fokus yang dapat dikenali.
- Layout mobile menghindari kolom terlalu sempit dan tabel tetap dapat digulir.
- Animasi dibatasi pada hover/focus dan menghormati `prefers-reduced-motion`.
- Tidak ada perubahan pada logika transaksi, hak akses, atau integrasi.
