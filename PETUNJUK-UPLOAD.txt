KONSEP STIFIn PLATFORM V0.4.0

1. Ekstrak ZIP ini.
2. Upload seluruh isi hasil ekstrak ke root repository GitHub dan timpa file lama.
3. Commit ke branch main.
4. Di Coolify, isi Environment Variables:

   STIFIN_API_BASE=https://apro.stifin.id/api
   STIFIN_PROMOTER_MODE=national

5. Pastikan DATABASE_URL dan kredensial admin tetap tersedia di Coolify.
6. Hapus STIFIN_BRANCH_CODES dari konfigurasi produksi nasional.
7. Redeploy dan tunggu health check berhasil.
8. Uji /tes-stifin, /wilayah, /api/promotor, dan /admin/leads.

Perubahan utama:
- sumber promotor nasional /proGet/pro/PRO dengan cache aman;
- sanitasi data promotor tanpa kontak atau field sensitif;
- pencocokan kandidat berdasarkan mapping, kabupaten/kota, lalu provinsi;
- lead idempoten wajib sebelum checkout produk Tes STIFIn;
- checkout hanya ke https://app.konsepstifin.com;
- rekonsiliasi pembayaran, order, biaya, promotor, jadwal, margin, dan audit;
- affiliate dan jalur jadi-promotor tetap memakai alur sebelumnya.

Panduan lengkap: docs/OPERASIONAL_PROMOTOR_NASIONAL.md

Jangan upload .env, node_modules, .next, token, password, atau data pelanggan.
